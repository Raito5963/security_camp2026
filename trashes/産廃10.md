| 関数名 | 役割 | 備考 |
| ---- | ---- | ---- |
| main() | 関数全体のまとめ役 | 初期化から公開までのクローンサイクルを統括する |
| process_repositories() | リポジトリを解析、処理する | ターゲット組織内のプライベートリポジトリが対象 |
| (初期チェック) | 必要な入力の存在と有効性を確認、信頼性を担保 | 組織名、ターゲットユーザ名、GitHub認証トークンなど |
| github_api() | APIの対話のための通信ラッパー | HTTPリクエストのハンドリングや認証管理を担当 |
| get_all_repos() | 組織内の全リポジトリを列挙 | プライベート、内部リポジトリのみを対象 |
| create_repo() | 検出したリポジトリで追跡可能な宛先リポジトリを作成する | 「Shai-Hulud Migration」などの識別子によって追跡可能になる |
| make
mrepo_public() | プライベートだったリポジトリを攻撃者管理下で公開する | データ露出とフィンガープリンティングが可能になる |
| migrate_repo() | コミット、ブランチ履歴を取得する | 二次攻撃や後続の悪用が可能になる |
